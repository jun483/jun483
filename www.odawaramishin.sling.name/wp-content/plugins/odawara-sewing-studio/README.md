# Odawara Sewing Studio

小田原ミシン公式

生地計算・型紙・副資材・ミシン診断を行う
WordPressプラグインです。

---

## 機能

- 生地計算
- 副資材計算
- 型紙
- 洋服用尺計算
- PDF出力
- ミシン診断
- 布診断

---

## 開発環境

- WordPress 6.x
- PHP 8.2+
- Visual Studio Code
- Git
- GitHub
